# Vibe Game - Дрон проти шахедів 🎮

## Опис
3D гра на Three.js, де ви керуєте дроном у нічному місті та захищаєте його від хвиль ворожих шахедів.

## Особливості
- ✨ Повний 3D-рендеринг з Three.js
- 🌃 Процедурно згенероване нічне місто
- 🎯 Система хвиль ворогів
- 💥 AABB колізії
- 🎮 Підтримка desktop та mobile управління
- 🔊 Звукові ефекти
- 📊 HUD з статистикою гри
- ⏸️ Система паузи

## Як запустити
1. Відкрийте файл `index.html` у браузері
2. Гра запуститься автоматично

**Важливо:** Для коректної роботи потрібне інтернет-з'єднання (для завантаження Three.js з CDN).

## Керування

### Desktop
- **WASD** - рух дрона
- **Миша** - поворот камери/прицілювання
- **ЛКМ (ліва кнопка миші)** - стрільба
- **ESC** - пауза

### Mobile
- **Віртуальний джойстик** (лівий нижній кут) - рух
- **Червона кнопка** (правий нижній кут) - стрільба
- Альтернативно: тап по правій стороні екрану для стрільби

## Ігрова механіка
- 🎯 **Мета:** Знищуйте ворожих шахедів та захищайте місто
- ❤️ **Життя:** У вас є 3 життя
- 🏙️ **Здоров'я міста:** Місто має 100% здоров'я
- ⭐ **Рахунок:** +10 балів за кожного знищеного ворога
- 🌊 **Хвилі:** Кожна наступна хвиля додає +3 ворогів
- ⏱️ **Час:** Виживайте якомога довше!
